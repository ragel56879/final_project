# TODO-лист на GO

REST API сервис для управления задачами.

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

В директории `pkg` находятся директории:
- `server` для запуска сервера,
- `api` HTTP хендлеры и вспомогающие функции,
- `db` работа с базой данных,
- `config` конфигурация

Чтобы запустить нужно создать .env файл с `PORT=7540 DBFILE=scheduler.db`

Дополнительно реализована строка поиска (в tests/settings.go `Search` должен быть параметр `true`)
